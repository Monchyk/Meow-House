Deep House

An interactive collection of living light, generative drawings, small games, and visual experiments. Pick any door below; the main piece is first.

Before you beginSome pages flash, pulse, or move quickly. If that is uncomfortable, close the page or use your browser's Back button. Smart lights are optional; every screen still works without them.

One computer first; phone or second screen later

The main experience runs in the browser on the computer that started Deep House. A phone, tablet, television, or second computer is optional: it can control or watch alongside the main screen.

To join from a phone, both devices must use the same Wi-Fi and you need the computer's IP address:

  1. On Windows, open Command Prompt.
  2. Type ipconfig and press Enter.
  3. Find IPv4 Address. It looks like 192.168.1.23.
  4. On the computer, open http://YOUR-IP:8800/qr/, replacing YOUR-IP with that number.
  5. Use the QR launcher's simple browser steps to show one QR code. Scan it with the phone's Camera app.
