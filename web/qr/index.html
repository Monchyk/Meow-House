Phone and second-screen launcher

Deep House itself runs on the main computer. Use this launcher only when a phone, tablet, television, or second computer should control or watch alongside it.

Put this launcher on your phone with one QR code

  1. Make sure the computer and phone use the same Wi-Fi.
  2. On the computer, right-click an empty part of this page.
  3. In Chrome or Edge, click Create QR code for this page.
  4. Open the Camera app on the phone and point it at the QR code.
  5. Tap the message that appears. This launcher opens on the phone.
  6. Tap one of the available doors below.

If your browser has no “Create QR code” option, type the address shown above into the phone's browser instead.
